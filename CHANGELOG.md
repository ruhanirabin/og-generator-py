## [0.1.0.dev0] - 2026-08-15

### Added

- A root `VERSION` file as the single source of truth for package and runtime
  version reporting.
- The `ogimg --version` command.
- Public project history and contributor-oriented documentation.
- The installable `ogimg` Python command-line application.
- A deterministic 1200×630 Open Graph image preset.
- Five procedural linear and radial gradient themes.
- Measured, balanced title wrapping with explicit overflow errors.
- Optional transparent PNG and WebP logos with automatic or explicit
  placement.
- Deterministic PNG and quality-85 WebP output.
- Predictable title-derived output filenames.
- A cross-platform helper for generating images from a list of titles.
- Bundled Noto Sans Bold under the SIL Open Font License 1.1.
- Tests for layout, rendering, themes, logos, formats, filenames, and the CLI.
